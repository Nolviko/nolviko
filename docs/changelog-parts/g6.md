# G6 (importer) — beta.18 core side + importer 1.1.0

Branch b17/g6-importer (core) and extensions-src/nolviko/importer (its own repository, commit 9dd7b5a, version
1.1.0). Verification: php -l and PHPCS only; tests NOT RUN (owner: once after merge).

Benchmark bug list (beta.12 report) and where each is fixed:
- P1 members-only forums public after publish: the extension reads source access (SMF member_groups, MyBB
  forumpermissions with parent inheritance, phpBB ACL incl. roles, NEVER wins); the core maps it to guest/member
  view/read and extra reader groups on publish. Source password forums become staff only (an administrator can set
  a Nolviko forum password, ADR-041); redirect forums become link sections.
- P1 MyBB poll separator `||~|~||` (1.0.0 used `||~|`): fixed, the old form still read.
- P1 SMF several attachment folders: panel field takes one folder per line (`N=path`); folders in SMF's own
  `attachmentUploadDir` are found automatically (same path, or same name next to the first folder).
- P2 phpBB poll s9e XML: poll questions/options are plain text.
- P2 SMF `[attach id=N]`: converted to inline attachments.
- P2 SMF legacy `?msg=N` and `;`-separated dlattach URLs: redirect/download (core LegacyLink).
- P2 inline images as download links: images shown inline (mime from stored bytes, `[img]` legacy URL).
- P3 PM chains: conversations kept per owner (core migration 0085, extension chain keys); stock SMF/MyBB have no
  PM files, the preflight says so (phpBB PM files imported).
- P3 `import-<job>-threads-N-N` slugs: slugs from the topic title.
- P3 preflight counts: exact counts (categories apart, messages not mailbox copies, post attachments only).
- Jobs started with importer 1.0.0 restart with 1.1.0 (reader version 2).
