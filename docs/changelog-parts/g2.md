# G2 - search, reading and member lists (roadmap Beta 17 scope, release 0.1.0-beta.18)

Branch `b17/g2-search`. All nine features coded.

## Added
- 09 Search inside a thread (`thread` filter; the thread page has a search box; results link to the right page).
- 11 Titles-only search (FULLTEXT / PG GIN index on `threads.title`, migration 0065; one result per thread).
- 26 Search sort: newest (default), oldest, relevance (relevance orders the newest 1,000 matches).
- 12 Mark all forums read: one board-wide cutoff row per member (`member_read_cutoffs`, 0067), POST `/forums/read`.
- 13 First unread post: GET `/threads/{thread}/unread` jumps to the right page and anchor (last post when all read).
- 14 Member-chosen forum thread order: title, most replies, newest threads (indexes of 0066). Numbered pages, at most
  100; the default last-activity order keeps keyset pagination (ADR-014).
- 17 My drafts: `/drafts` lists thread and reply drafts with continue and bulk delete.
- 18 Followed: `/following` lists subscriptions and bookmarks with bulk removal; a slot for forum subscriptions (G4).
- 24 Member directory: username-prefix search and sort by name or newest members (index 0068); offset pages (max 100).

## Decisions
- Alternate sorts use numbered pages capped at 100 pages to keep large-forum cost bounded.
- Member directory: sort by post count left out: there is no stored per-member counter and counting on the fly would
  scan the posts table; can follow with a stored counter.
- Mark-all is one row per member, not one per forum.
