Status: all six features coded (02, 08, 19, 20, 33, 37).

## Added
- 02 Personal folders (`private_folders`, `private_folder_items`, migration 0061; folders = labels, a conversation can be
  in several; `source_key` + `PrivateFolders::ensure()` for importers) and "Remove from my box" (`removed_at`, 0060;
  only the actor's row; a new visible message brings it back).
- 08 Multi-recipient conversations, `limits.message_recipients` site setting (default 10, 1-50); throttle once per message.

- 20 Hidden recipients (`hidden`, `invited_by`; replies carry `visible_to` = sender; participants list shows them only
  to their sender and themselves; personal export query NOT yet filtered by `visible_to` - TODO).
- 33 `pm.max_conversations` group permission (0 = unlimited; any group without a limit = unlimited; user override wins);
  full box refuses with `conversation_box_full` naming the recipient.
- 37 Formatted DMs: already used BbcodeRenderer/MarkdownToBbcode; label updated.

## Decisions

  when one other member remains (group replies skip block checks).
- No new routes: `/conversations` accepts POST (folder/draft actions), `?view=drafts|folders`, `?folder=`.
